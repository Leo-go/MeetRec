# Запись встречи (MeetRec)

Бесплатная запись встречи на Mac: микрофон и звук компьютера в один WAV, без видео. Файл остаётся на этом Mac.

Это локальный аналог программ вроде Piezo и Quick Audio Recorder. Картинка экрана не сохраняется. Для звука встречи macOS всё равно просит доступ «Запись экрана» — так устроена выдача системного звука.

## Как пользоваться

После запуска открывается окно **Запись встречи**.

- Кнопка **Начать запись** или меню **Файл → Начать запись** (⌘R).
- **Остановить и сохранить** — готовый файл откроется в Finder.
- **Настройки** и список в окне: микрофон и встреча, только звук компьютера, только микрофон.
- **Файл → Открыть папку записей**.

Файлы: `~/Recordings/MeetRec/встреча-YYYY-MM-DD_HH-mm-ss.wav`.

Первый запуск спросит доступ к микрофону и к записи экрана. На macOS 27 это пункты «Запись экрана и системного звука» и, если он есть отдельно, «Запись системного звука». Если переключатель уже включён, а звук компьютера всё равно не пишется, выключи MeetRec, включи снова и перезапусти приложение: старая сборка оставляет разрешение, которое к новой подписи не подходит.

## Сборка

Нужны Command Line Tools (`swiftc`) и macOS 14 или новее. Сборка проверена на Apple Silicon.

```bash
make
open MeetRec.app
```

`make clean` удаляет собранное приложение. Исходник один: `Sources/main.swift`.

## Как устроено

- Окно и меню «Файл» / «Настройки» — AppKit.
- Звук компьютера — ScreenCaptureKit, кадр 2×2 выбрасывается, в файл идёт только аудио.
- Микрофон — `AVAudioEngine`.
- Оба потока смешиваются в 16-bit PCM WAV, 48 kHz, стерео.
- Промежуточные `.caf` лежат во временной папке сессии и удаляются после сведения.

Идентификатор пакета: `local.leogo.MeetRec`. Подпись локальным сертификатом «MeetRec Local» в связке ключей, чтобы разрешение на запись экрана не сбрасывалось после каждой сборки. `make` создаёт сертификат сам, ключ лежит в `~/Library/Application Support/MeetRec/signing` и в репозиторий не входит.

В git не кладутся собранное `MeetRec.app`, файлы записей и сертификат. Аудио остаётся в `~/Recordings/MeetRec`.
